# Teevolution Hub public roadmap

This roadmap describes product goals, not implementation details or device
protocols. Dates will be announced only when work is ready to ship.

## 1. Terra Pro XD9 driver foundation

- Complete a reliable Windows-first configuration layer for supported XD9
  options.
- Build safe backup, verification, diagnostics, and recovery-oriented flows.
- Validate device behavior before exposing a setting in the product.

## 2. UI and UX design

- Establish the Teevolution Hub design system and desktop layouts.
- Start with a device home screen: discover devices, select one, then open its
  settings.
- Design clear views for dashboard, performance, buttons, lighting, profiles,
  macros, settings, and diagnostics.

## 3. Desktop application

- Deliver a polished Windows control centre for supported XD9 features.
- Add local profiles, import/export, safe apply and restore workflows, and a
  lightweight system-tray experience.
- Keep unsupported or experimental device capabilities clearly labelled.

## 4. Future ecosystem support

- Extend through capability-aware support for future Teevolution peripherals.
- Explore display-dongle themes, widgets, and community content only when the
  corresponding hardware capabilities and safety requirements are established.
- Evaluate a limited web edition and an iOS companion where platform support
  makes the experience reliable and honest.

## Release principles

- Reliability and safe device configuration come before feature breadth.
- User data, diagnostics, and device backups remain local by default.
- Public releases will include clear support, licensing, and contribution terms.
