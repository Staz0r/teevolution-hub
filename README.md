# Teevolution Hub

Teevolution Hub is a planned Windows-first control centre for Teevolution
peripherals, starting with the Terra Pro XD9. The goal is a fast, clean, and
modern desktop experience for configuring supported devices, managing local
profiles, and viewing device status.

## Current status

This repository currently contains the public product direction and roadmap.
No application source, device protocol material, or release build is published
yet.

## Product direction

- A reliable driver foundation for supported Terra Pro XD9 configuration.
- A clean, modern desktop UI designed around selecting a connected device
  before entering its settings.
- Local profile management, safe configuration workflows, diagnostics, and a
  lightweight Windows tray experience.
- A scalable device model for future Teevolution mice, keyboards, headsets,
  receivers, and display dongles.

See the public [roadmap](docs/ROADMAP.md) for the planned delivery order.

## Community and source availability

Teevolution Hub is not yet open for contributions and no license has been
selected. Source availability, contribution terms, and release licensing will
be announced before any application source is published.

## Brand direction

The initial visual direction uses Teevolution green (`#78BE1F`), black
(`#000000`), and white (`#FFFFFF`) with a clean, modern interface.
